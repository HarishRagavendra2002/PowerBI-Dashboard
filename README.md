Student Habits vs Academic Performance - Power BI Dashboard

This repository contains a Power BI dashboard project that explores how various student habits influence academic performance. By analyzing behavioral patterns such as study time, internet usage, sleep schedule, and extracurricular activities, this project aims to uncover actionable insights for educators, parents, and policy makers.

Project Objective

To visualize and analyze the relationship between students' daily habits and their academic performance using an interactive Power BI dashboard. This can help identify which behaviors contribute positively or negatively to students' grades and overall academic outcomes.

Dataset

The dataset includes features such as:
- Study time
- Sleep duration
- Internet usage
- Attendance
- Parental involvement
- Time spent on social media
-  GPA
- Participation in extracurricular activities

> Dataset Source: Kaggle 

Tools Used

- **Power BI Desktop** – For data modeling and dashboard creation
- **Microsoft Excel / CSV** – For initial data cleaning (optional)
- **DAX** – For calculated columns and measures
- **Power Query Editor** – For ETL process

Features of the Dashboard

- Correlation heatmaps between habits and GPA
- Filters by gender, class, school, etc.
- KPI cards for average GPA, study hours, sleep hours
- Interactive charts showing distribution of habits
- Trend analysis of performance based on habit changes

How to Use

1. Clone the repository or download the `.pbix` file.
2. Open the `.pbix` file in Power BI Desktop.
3. Refresh the data source or import your own dataset using the same structure.
